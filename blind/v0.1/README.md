# Paquete ciego Bitmapverse v0.1

Este directorio contiene únicamente el material permitido para la **Prueba A: independencia del resolver**.

La persona o instancia implementadora debe comenzar por `TASK.md`, verificar `PACKAGE_MANIFEST.json` y trabajar sin acceso al resto del proyecto Bitmapverse.

El paquete no contiene:

- resultados esperados;
- oráculo de comparación;
- código o pruebas de la primera implementación;
- ejecución del Consejo de Señales;
- instrucciones para reconstruir evidencia desde Internet.

Superar esta prueba demostraría que el contrato permite obtener el mismo resultado desde la misma evidencia congelada. No demostraría que una segunda parte puede reconstruir esa evidencia desde infraestructura Ord viva.
